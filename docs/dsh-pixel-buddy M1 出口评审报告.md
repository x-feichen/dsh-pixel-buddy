## 3. MVP 冒烟清单（页面手动验收，已于 devhost 实测）

1. ✅ 页面加载后右下角出现占位像素鸭，默认无徽章
2. ✅ "运行中"→ 蓝点淡入；重复点击不闪烁
3. ✅ "成功"→ 绿勾，2.5 秒后自动淡出
4. ✅ "报错"→ 红叹号粘滞；后续"成功/运行中/需要人工"均不覆盖（用户已确认符合 D2 设计）
5. ✅ 单击宠物消除粘滞徽章，之后事件恢复正常驱动
6. ✅ "需要人工"→ 黄问号粘滞，行为同上
7. ✅ 滚动页面宠物固定悬浮，不遮挡主内容
