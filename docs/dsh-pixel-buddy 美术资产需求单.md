## 1. 背景

dsh-pixel-buddy 在页面右下角常驻一个像素风格宠物形象（MVP 为单张静态图），右上角叠加状态徽章。本需求单需一次性锁定形象与徽章的全部美术规格，供设计阶段直接开工，避免中途返工。

选型结论（本需求单采用，评审时确认）：**MVP 首发形象为「鸭子」**，备选「猫」；狐狸/狸猫等列为后续皮肤系统候选，不在本期交付范围。

## 2. 资产清单（总览）

| 编号 | 资产           | 数量 | 说明                                         |
| ---- | -------------- | ---- | -------------------------------------------- |
| A1   | 宠物本体精灵图 | 1 张 | 单张静态图，**无任何动画帧**                 |
| A2   | 状态徽章图形   | 4 枚 | 待机无徽章；运行中•、需要人工?、报错!、成功✓ |
| A3   | 色板与设计规范 | 1 份 | 明/暗主题色值、描边、投影等规则              |
| A4   | (推荐)源文件   | 1 套 | 含像素网格分层源文件，便于后续皮肤/表情扩展  |

资源总量红线（PRD §5）：本体 1 张 + 徽章 4 枚，**不接受多帧动画序列**。

## 3. 宠物本体（A1）

### 3.1 形象定义

- **形象**：鸭子（备选：猫，若评审改选，仅影响 §3.3 的耳朵预留位约束，其余规格不变）。
- **气质**：呆萌、中性、无攻击性，匹配开发者工具调性；避免过于幼稚化。
- **朝向**：默认朝右或正视（正视优先，利于徽章右上角布局与后续表情扩展）。
- **姿态**：静止站立/坐姿，单帧。禁用任何暗示动作的构图（张翅、跳跃等）。

### 3.2 交付尺寸

| 项         | 要求                                                                                                                  |
| ---------- | --------------------------------------------------------------------------------------------------------------------- |
| 画布尺寸   | 32px、40px、48px 三档正方形各交付一版（或 1 张高倍源图 + 三档导出），实际使用档位由前端联调确定                       |
| 像素颗粒度 | 以 48px 画布为准，建议 12×12 或 16×16 逻辑像素网格（即单逻辑像素 3~4 物理像素）；**必须整像素对齐，禁止半像素抗锯齿** |
| 缩放       | `image-rendering: pixelated` 呈现，源图需保证 1x/2x/3x 整数倍缩放不糊                                                 |
| 安全区     | 画布四边预留 ≥2 逻辑像素空白（出血/呼吸空间）；**右上角区域额外预留徽章叠放位（见 §4）**                              |

### 3.3 形象结构约束（为徽章与后续版本让位）

- 头部轮廓以圆形/圆润为主；**右上 1/4 区域避免尖长突出物**（如尖耳、翘尾羽进入徽章叠放区）。
- 若选猫：耳朵需压圆、压小，整体不超过头部轮廓外扩 1 逻辑像素。
- 主色为暖色系（鸭黄/暖白），与徽章四色（蓝/琥珀/红/绿）拉开色相与明度，避免撞色。
- 五官（眼/喙）比例适当放大，为后续版本的表情系统留表达空间。

### 3.4 明暗主题

本体需分别适配明/暗两套宿主主题：至少提交明暗两版的描边色/暗部色规范（可同图 + 描边色规则，或两张图），保证暗色背景下轮廓清晰、不糊底。

## 4. 状态徽章（A2）

### 4.1 布局与尺寸

> **v0.2 修订（产品裁决 2026-09-05，已实现）**：徽章位置由"本体右上角"调整为**本体头顶正上方居中**（水平居中、顶部略出血约 14% 本体高度），尺寸由本体 40%~50% 收敛为 **50% 整**（48px 本体对应 24px）。正式设计资产请按新布局产出。

| 项   | 要求                                                                                           |
| ---- | ---------------------------------------------------------------------------------------------- |
| 位置 | 叠加于本体**右上角**，可部分出血至本体画布外（需设计给出精确偏移坐标，前端按坐标实现）         |
| 尺寸 | 建议为本体尺寸的 40%~~50%（如 48px 本体配 20~~24px 徽章），保持"不喧宾夺主"（PRD §4.3）        |
| 结构 | 圆形底色 + 单字符符号；符号与底色**双重编码**，任一单独存在均可辨识（色觉可及性，PRD §4.3/§5） |

### 4.2 四枚徽章规格

| 状态     | 符号         | 底色（明主题参考值）   | 备注                                        |
| -------- | ------------ | ---------------------- | ------------------------------------------- |
| 运行中   | `•` 实心圆点 | 蓝 `#3B82F6` 附近      | —                                           |
| 需要人工 | `?`          | 琥珀/黄 `#F59E0B` 附近 | 需与鸭黄本体做明度/描边区分，避免与本体粘连 |
| 报错     | `!`          | 红 `#EF4444` 附近      | —                                           |
| 成功     | `✓`          | 绿 `#22C55E` 附近      | —                                           |

> 以上色值为占位参考，最终以 A3 色板规范为准；需同时给出暗主题版本色值。

### 4.3 徽章绘制要求

- 符号使用像素风格字符图形（非系统字体直排），笔画在 20px 内清晰可辨；圆点/问号/叹号/勾号的具体画法由设计定稿。
- 徽章自带 1 逻辑像素深色描边（或等效方案），保证在任意本体色与任意页面背景上可辨。
- 暗主题下徽章底色/描边需有对应规范。
- **本体不做任何描边/滤镜换色**，颜色信息收敛于徽章本身（PRD §4.3）。

## 5. 色板与设计规范（A3）

设计需随资产提交一页规范，至少包含：

1. 本体主色/辅色/描边色的明暗两套色值（hex）。
2. 四枚徽章底色/符号色/描边色的明暗两套色值（hex）。
3. 徽章相对本体的精确偏移坐标（以 48px 画布为基准）。
4. 像素网格规格与对齐规则声明。
5. (推荐)后续皮肤/表情的扩展约束说明。

## 6. 交付格式与验收标准

### 6.1 交付格式

| 交付物 | 格式                                                                       |
| ------ | -------------------------------------------------------------------------- |
| 本体   | PNG（透明背景）+ 源文件（Aseprite/.pixel 或分层 PSD/SVG）                  |
| 徽章   | 优先 **SVG 或纯 CSS**（便于前端改色与暗主题适配）；若为位图则 PNG 透明背景 |
| 规范   | Markdown 或 PDF 一页纸                                                     |

### 6.2 验收标准（设计交付时逐条核验）

1. 本体为单张静态图，无动画帧；32/40/48px 三档可用且整像素对齐。
2. 本体右上 1/4 徽章区无形象元素侵入；徽章叠放后两者视觉协调。
3. 四枚徽章符号在 20px 尺寸下单看可辨（只看符号不看颜色也能区分状态）。
4. 明暗两套主题下，本体与徽章均清晰可辨、对比度达标（徽章文字/符号对底色对比度 ≥ 4.5:1）。
5. 徽章四色与本体主色不撞色；琥珀徽章与鸭黄本体可明确区分。
6. 资源总量符合 §2 红线。
7. 色板规范与坐标规范齐备，前端可据此直接实现，无需二次猜测。
